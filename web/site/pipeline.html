Runtime honesty: the KPI, latency, fault-injection and scalability numbers on this page come from the local streaming fallback (in-process bounded queue → the same StreamProcessor the Kafka and Spark adapters call) on a 2-vCPU sandbox. Apache Kafka (KRaft) and Spark Structured Streaming were executed separately on a single-node pseudo-distributed cluster — see Execution status of runtimes below and docs/bigdata.md. None of these are multi-node cluster numbers.
