About the project

HeatFlood Sentinel — an MS Data Science thesis artefact from NED University, Karachi

An end-to-end, reproducible research system for heatwave and flash-flood forecasting and detection in Pakistan: real ERA5 data, deep and classical models benchmarked with significance tests, a streaming alert engine and a public dashboard.

How this site is hosted

Static site on GitHub Pages (the gh-pages branch of the code repository). There is no backend server.

  • The REST API is not hosted. The FastAPI service (/api/v1, SSE alert stream, token-protected acknowledge / bulletin / live-refresh) runs only locally (make api). Its read-only responses were exported once to JSON files under api/ with FastAPI's TestClient, and a small adapter in the page answers the dashboard's API calls from those files. See API Docs.
  • The live snapshot is real and scheduled. A GitHub Actions workflow on the code repository's main branch runs every 6 hours: it checks out the code and this site, runs hfs.streaming.live_feed (Open-Meteo forecast/current + ERA5 archive, per-city NWP-to-ERA5 bias correction, trained detectors, alert engine) and commits api/live.json to gh-pages. If Open-Meteo is unreachable, the previous snapshot stays in place — nothing is synthesised.
  • Kafka / Spark were not executed. Both the published results and the live job use the local streaming fallback (same StreamProcessor).
  • Historical pages (forecasts, detection, benchmarks, streaming) show the held-out 2022 test-year outputs of release v0.1.0 and do not change between live updates.

Disclaimer

HeatFlood Sentinel is a research prototype and not an official warning system. Always follow the Pakistan Meteorological Department (PMD), NDMA and the provincial PDMAs. Flash-flood outputs are reanalysis proxies. Data: Copernicus ERA5 (C3S/ECMWF) via Open-Meteo; Open-Meteo forecast data under CC BY 4.0 (non-commercial).
